# S2 — translateLocally cobre os 4 pares

**Data**: Pendente

## Comandos

```powershell
# Listar modelos disponíveis
translateLocally.exe -a

# Baixar modelos
translateLocally.exe -d en-pt-tiny
translateLocally.exe -d pt-en-tiny
translateLocally.exe -d en-es-tiny
translateLocally.exe -d es-en-tiny
```
