# S4 — Separação de fontes num trecho real

**Data**: Pendente

## Comandos

```powershell
# Extrair trecho de 60s
ffmpeg -y -ss 300 -t 60 -i filme.mp4 -ac 2 -ar 44100 -c:a pcm_s16le s4_in.wav

# Separar
Measure-Command {
  sherpa-onnx-offline-source-separation.exe `
    --spleeter-vocals=<models>/spleeter-2stems-fp16/vocals.fp16.onnx `
    --spleeter-accompaniment=<models>/spleeter-2stems-fp16/accompaniment.fp16.onnx `
    --num-threads=6 --provider=cpu `
    --input-wav=s4_in.wav `
    --output-vocals-wav=s4_vocals.wav `
    --output-accompaniment-wav=s4_accompaniment.wav
}
```
